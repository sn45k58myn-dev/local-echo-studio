# Contributing

Use GitHub Issues to discuss observations or proposed work. For a code or documentation change, fork the repository, make a focused change and open a pull request.

- Report the printed model, FCC ID and board marking where available. Include expected and actual behaviour, your test conditions, and whether the evidence came from your unit, a public source or an inference.
- Use public documents or hardware you own and are authorized to inspect. Link third-party photos. Upload only images you have permission to share.
- Crop or redact serial numbers, MAC addresses, QR codes, account details, host names and personal audio. Keep raw logs and proprietary firmware out of issues and pull requests.
- Keep powered tests external to the enclosure. Prefer normal, documented interfaces and ordinary stock behaviour. This repository accepts hardware observations, host tooling and work using supported installation or recovery paths.
- Run `python -m unittest discover -s tests -v` before submitting host-tool changes. Include a synthetic regression test for changed signal measurements.

Contributions must be your own work or appropriately licensed and attributed. Original contributions to this project use the MIT License.
